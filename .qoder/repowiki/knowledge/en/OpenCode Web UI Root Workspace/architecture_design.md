This is a Bun workspaces monorepo root whose only purpose is to orchestrate the `packages/app` sub-package. All npm scripts (`dev`, `build`, `serve`, `preview`, `typecheck`) delegate via `bun --cwd packages/app` to that package's own scripts, so the root holds no application code — it defines the workspace catalog of shared dependency versions, patch file mappings, and tooling configuration (TypeScript extends `@tsconfig/bun`, Bun install policy via `bunfig.toml`). The actual application lives under `packages/app` and is built by Vite with SolidJS, producing static assets in `packages/app/dist` for deployment on any static host or reverse proxy.
