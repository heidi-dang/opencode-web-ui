## Phase 1 — Security Changes

### SSRF Removal
- `/api/remote-proxy` middleware and `X-Target-URL` removed from `vite.config.ts`, `server-health.ts`, `sw.js`.

### Fixed Proxy Validation
- `VITE_OPENCODE_SERVER_URL` validated at Vite startup: rejects credentials, unsupported protocols, invalid syntax. Hard-fails before proxy registration. Target pathname preserved. Hop-by-hop headers stripped. SSE unbuffered.

### Host Hardening
- `host: "127.0.0.1"` (was `0.0.0.0`), `allowedHosts: false` (was `true`).

### Credential Lifecycle
- Passwords stored in `sessionStorage` only. Legacy `localStorage` migrated on access. Server removal clears all.
- 8 credential lifecycle tests pass.
- Adding password never puts it in localStorage.
- Two servers cannot read each other's credentials.

### Mobile Logger
- `/api/mobile-log` endpoint and plugin removed.

### Type-Check Comparison
- **0 errors** after fixing 12 pre-existing errors.
