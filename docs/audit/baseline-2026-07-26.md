## Standalone Adaptations

The following behaviours differ from official OpenCode:

1. Remote proxy (`/api/remote-proxy`) — allows browser to pick any target URL (SSRF risk)
2. Mobile log receiver (`/api/mobile-log`) — logs browser debug data to server filesystem
3. `/opencode-server` development proxy — forwards to local opencode serve
4. All interfaces host binding (`0.0.0.0`) with unrestricted `allowedHosts: true`
5. Bundle includes @opencode-ai/client from vendored tarball
6. Ghostty web terminal, directory picker, and syntax highlighter are loaded as async chunks

These are the focus of Phase 1 remediation.
