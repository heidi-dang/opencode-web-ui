## Phase 1 — Security Changes

### SSRF Removal
- Removed `/api/remote-proxy` endpoint (arbitrary proxy via `X-Target-URL` header).
- Updated `sw.js` to no longer bypass cache for `/api/remote-proxy`.

### Fixed Proxy Validation
- `VITE_OPENCODE_SERVER_URL` is validated at startup:
  - Rejects URLs with username/password credentials.
  - Rejects unsupported protocols (only `http:` and `https:` allowed).
  - Rejects invalid URL syntax.
  - Fails hard with a configuration error before proxy registration.
- Target pathname is preserved.
- Dead fallback `server.proxy` branch removed.
- Hop-by-hop headers stripped.
- SSE remains unbuffered.

### Host Hardening
- Default Vite host changed from `0.0.0.0` to `127.0.0.1`.
- `allowedHosts` changed from `true` to `false`.

### Password Lifecycle
- Passwords stored in sessionStorage (not localStorage).
- On server add: password captured to sessionStorage, only a lookup key persisted to localStorage.
- On page reload within same tab: password restored from sessionStorage.
- On server removal: sessionStorage and any legacy localStorage cleared.
- On re-adding same URL: old password is not recovered.
- Legacy localStorage credentials are migrated to sessionStorage on first access.

### Mobile Logger
- Removed `/api/mobile-log` endpoint and `mobile-log-receiver` Vite plugin.
- Removed `mobile-debug.log` file writing.
